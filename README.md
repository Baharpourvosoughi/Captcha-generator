# Audio & Image CAPTCHA Generator 🔐

A lightweight Python utility to generate secure audio (WAV) and visual (PNG) CAPTCHA challenges for authentication flows.

## Features

- Generates numeric audio CAPTCHAs for accessibility.
- Generates alphanumeric image CAPTCHAs with noise and distortion.
- Uses Python's `secrets` module for cryptographically secure text generation.

## How to Run

1. Install dependencies:
```bash
   pip install -r requirements.txt
```
2. Run the script
```bash
      python main.py
```
Generated files will be saved in the output/ directory.
